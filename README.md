# 📚 E-Learning Platform

A modern, fully responsive **E-Learning website** built with **HTML5, SCSS, and vanilla JavaScript**. It includes course listings, instructor profiles, testimonials, and complete authentication pages — designed with a clean UI and mobile-first approach
---

## ✨ Features

- 🏠 **Home Page** — Hero slider with call-to-action buttons
- 📖 **Courses Page** — Browse available online courses
- 👥 **Team Page** — Instructor / mentor profiles
- 💬 **Testimonials** — Student reviews and feedback
- 📞 **Contact Page** — Contact form with validation
- 🔐 **Authentication** — Sign In & Sign Up pages
- 📱 **Fully Responsive** — Mobile, tablet, and desktop friendly
- 🎨 **SCSS Architecture** — Modular, maintainable styling
- ⚡ **Vanilla JavaScript** — DOM manipulation & form validation

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/emuhammadali/e-learning.git
cd e-learning
```

### 2. Open in Browser

Simply open `index.html` in your browser — no build step required.

### 3. (Optional) Compile SCSS

If you want to edit SCSS files, install Sass:

```bash
npm install -g sass
sass --watch scss:css
```

---

## 🎨 Customization

- **Colors** → Edit variables in `scss/_variables.scss`
- **Fonts** → Update `@import` in main SCSS file
- **Images** → Replace files in `img/` folder
- **Content** → Edit individual `.html` files
